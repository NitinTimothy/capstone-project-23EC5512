## 🚀 Final Capstone Project: Smart Buy Advisor
📁 **Location**: [`./smart-buy-advisor`](./smart-buy-advisor/)

**Smart Buy Advisor** is a financial decision-making React application that calculates whether buying an entity (smartphone, laptop, car, TV) in **Full Cash** vs. **EMI (Standard & No-Cost)** and investing the retained cash surplus yields net financial savings over time.

## 🛠️ How to Run Smart Buy Advisor Locally
1. Navigate to the project directory:
   ```bash
   cd smart-buy-advisor
   ```
2. Install dependencies & launch:
   ```bash
   npm install
   npm run dev
   ```
3. Open `http://localhost:5173/` in your browser.
